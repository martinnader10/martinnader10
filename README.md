# Martin Nader — Personal Digital Ecosystem

A personal portfolio website showcasing selected projects, skills, learning milestones, and public profiles.

## Live website
After enabling GitHub Pages, the site will be available at:
https://martinnader10.github.io

## Built with
- HTML
- CSS
- JavaScript

## Deployment
This repository is configured for a GitHub Pages user site. In the repository settings, open **Pages**, choose **Deploy from a branch**, select **main** and **/(root)**, then save.

## Notes
Project descriptions and technologies are presented as a portfolio overview. This repository contains the portfolio website, not the source code for ORNVIA or MedGenius.
