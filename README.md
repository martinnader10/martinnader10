## Publishing

GitHub Pages serves the static website. In repository Settings → Pages, select Deploy from a branch, then choose the intended publishing branch and the root folder.

A custom domain such as martin-nader.com is separate from the repository name and requires a domain registration (or a suitable free subdomain provider) plus DNS configuration. The site can use a custom domain while the code remains hosted on GitHub Pages.

## Important

This repository contains the public website only. It does not contain the private source code, credentials, original certificate files or private user data for other projects.
